<ListCard title="BuddhiAI CLI" imageIcon="/src/assets/code-block.svg" number="Developer Infrastructure">
- **AST-Powered Code Graph**: Extracts classes, methods, and call hierarchies via tree-sitter into SQLite.
- **Model Context Protocol (MCP)**: Provides `buddhi_search` and `buddhi_read` tools over StdIO.
- **Google Antigravity Harness**: Scaffolds `.agents/` workflows, domain specialists, rules, and safety hooks.
- **Spec-Driven Development (SDD)**: Enforces `/specify`, `/plan`, `/tasks`, `/implement`, and `/verify` lifecycles.
- **Multi-Language Support**: Python, TypeScript/JS, Go, Rust, C#, Java, Kotlin, Swift.
