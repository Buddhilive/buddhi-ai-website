BuddhiAI CLI is a Python command-line tool that builds a code graph for a software repository and provides related tools for coding agents. Its package includes commands for graph analysis, generated code documentation, project memory, and an Antigravity agent harness.

The MCP extra installs the `buddhi-mcp` stdio server. The project README and source code are available in the [BuddhiAI CLI GitHub repository](https://github.com/Buddhilive/buddhi-cli).

Start with the [installation guide](/cli/installation/) or browse the [CLI overview](/cli/).
