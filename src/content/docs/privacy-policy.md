## Scope

This notice covers the BuddhiAI CLI documentation website. It does not cover the CLI application or third-party services used with it.

## Current site behavior

The site provides documentation and a search index. It does not currently have user accounts, contact forms, or newsletter sign-ups. Search runs against the site's published index. The theme preference is stored in your browser's local storage.

Hosting this site on GitHub Pages is planned, but is not active yet. Google Analytics and Google AdSense are also planned and are not active. We will update this notice before enabling those services with details about their data use and available controls.

## Third-party websites

Links to other websites, including GitHub, are governed by those websites' own privacy notices.
